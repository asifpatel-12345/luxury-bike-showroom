A modern, high-performance single-page web application designed for a futuristic luxury superbike and hyperbike showroom. Built using **vanilla HTML5, CSS3, and JavaScript**, featuring dynamic filtering, modal specification popups, real-time search, and theme switching.

---

## 🔥 Key Features

- **⚡ Exclusive Fleet Catalogue**: Displays 10 premier flagship bikes including Kawasaki Ninja H2R, BMW S1000RR, Ducati Panigale V4R, TVS Apache RR310 BTO, Suzuki Hayabusa, and more.
- **🔍 Real-Time Live Search**: Instantly search bikes by model name or brand.
- **🎯 Dynamic Category Filter**: Filter fleet by *Hyperbike, Superbike, Naked/Street, and Cruiser*.
- **📊 Interactive Bike Specs Modal**: Detailed popups highlighting power, top speed, engine specs, and pricing.
- **🌙 Dark / Light Mode Toggle**: Smooth UI transition with futuristic glassmorphism and cyberpunk aesthetic accents.
- **📱 Fully Responsive Design**: Optimized for mobile, tablet, and ultra-wide displays.
- **📝 VIP Consultation / Booking Form**: Interactive booking system with auto-selecting model dropdowns.

---

## 🛠️ Tech Stack & Technologies Used

- **Frontend**: HTML5, CSS3 (Flexbox & CSS Grid, Modern Variables)
- **Scripting**: Vanilla JavaScript (ES6+ DOM Manipulation)
- **Icons**: FontAwesome v6
- **Typography**: Google Fonts (*Orbitron* & *Plus Jakarta Sans*)
